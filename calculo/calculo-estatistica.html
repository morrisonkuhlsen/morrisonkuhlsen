Cálculo na Estatística — Densidade, Média e Verossimilhança

Esta é a lição em que as nove anteriores se juntam. A probabilidade de uma variável contínua é uma integral; a densidade é uma derivada; a média é outra integral; e a melhor estimativa de um parâmetro sai de um máximo. Três painéis, um para cada ideia.

Densidade e acumulada A média Verossimilhança O caminho todo Exercícios

Densidade e acumulada

Em cima, a acumulada F(x) = P(X ≤ x): a chance de a variável ficar até x. Embaixo, a densidade f(x). As duas contam a mesma história de dois jeitos — a área sombreada embaixo é a altura de cima, e a inclinação de cima é a altura de baixo.

acumulada F(x) = P(X ≤ x) — tracejada, a tangente

densidade f(x) — sombreada, a área até x

A média é uma integral

Para dados, a média soma cada valor vezes a sua frequência. Para uma densidade, a soma vira integral: cada x pesado por f(x). Geometricamente, a média é o ponto de equilíbrio da curva — onde ela ficaria parada sobre um apoio. Mude a forma k de uma distribuição Gama e veja o apoio andar.

densidade f(x), com o apoio na média

x · f(x) — a área sombreada é a média

Máxima verossimilhança: a melhor estimativa é um máximo

Uma moeda deu k caras em n lançamentos. Para cada valor possível de p, a chance de ver exatamente esses dados é L(p) = pᵏ(1 − p)ⁿ⁻ᵏ: a verossimilhança. O melhor palpite para p é o que torna os dados mais prováveis — o topo da curva, onde a derivada zera.

verossimilhança L(p), dividida pelo valor máximo — tracejada, a tangente

log-verossimilhança ln L(p) — o máximo fica no mesmo lugar

O caminho todo

  1. Taxa de variação: quão rápido algo muda, em média e num instante.
  2. Limite: chegar perto sem chegar, para fugir do 0/0.
  3. Derivada: a inclinação num ponto, a curva vista de perto.
  4. Tabela de derivadas: as regras, tiradas uma vez e guardadas.
  5. Máximos e mínimos: onde a derivada zera está o melhor.
  6. Integral: a área como soma de faixas, o acúmulo.
  7. Teorema fundamental: derivar e integrar se desfazem.
  8. Tabela de integrais: as primitivas e as técnicas.
  9. Derivar e integrar lado a lado: as duas tabelas como uma escada.
  10. E aqui: probabilidade é área, densidade é derivada, média é integral, estimativa é máximo.

Daqui, as fórmulas interativas aprofundam cada peça: a normal, a integral gaussiana, o teorema central do limite, a regressão e a distribuição Beta, que é a verossimilhança desta página vista pelo lado bayesiano.

Teste você mesmo

1. A acumulada de uma variável é F(x) = x² para 0 ≤ x ≤ 1. Qual a densidade?

Ver resposta

A derivada da acumulada: f(x) = 2x, entre 0 e 1. Confira: a área sob 2x de 0 a 1 é 1.

2. Com densidade f(x) = 2x entre 0 e 1, qual a média?

Ver resposta

E[X] = ∫₀¹ x · 2x dx = ∫₀¹ 2x² dx = 2/3 ≈ 0,667. Os valores altos são mais prováveis, então a média fica acima de 1/2.

3. Qual a média de uma exponencial de taxa λ?

Ver resposta

E[X] = ∫₀^∞ x λe^(−λx) dx = 1/λ (integrando por partes). Com 3 clientes por hora, a espera média é 1/3 de hora.

4. Em 20 lançamentos de uma moeda, saíram 14 caras. Qual a estimativa de máxima verossimilhança de p?

Ver resposta

Derivando ln L = 14 ln p + 6 ln(1 − p) e igualando a zero: 14/p = 6/(1 − p), então p = 14/20 = 0,7.

5. Por que se maximiza ln L em vez de L?

Ver resposta

O logaritmo é crescente, então o máximo fica no mesmo lugar. E ele troca o produto de muitas probabilidades por uma soma, mais fácil de derivar e que não vira zero no computador.
