Limite — Chegar Perto Sem Chegar

Na lição anterior, a velocidade num instante esbarrou num 0 ÷ 0. A saída é não fazer a conta no ponto, e sim perguntar de que valor a função se aproxima quando x chega perto dele. Essa é a ideia de limite — e sobre ela se constroem a derivada e a integral.

Aproximando dos dois lados

Escolha uma função e encolha a distância h: os pontos se aproximam de a, um pela esquerda e outro pela direita. O que acontece com os valores de f?

Quão perto? O desafio do ε

“Se aproxima de L” tem um sentido preciso. Alguém escolhe uma margem ε em volta de L (a faixa horizontal), tão estreita quanto quiser. O limite é L se, para qualquer margem, existir uma distância δ em volta de a (a faixa vertical) em que a curva fica toda dentro da margem.

Quando o limite não existe

Para o limite existir, os dois lados precisam chegar ao mesmo número. Há três jeitos clássicos de isso falhar — todos aparecem no primeiro gráfico:

Salto: cada lado vai para um número, mas números diferentes. Os limites laterais existem; o limite, não.

Explosão: os valores crescem sem parar. Escrever “= ∞” é um jeito de dizer como o limite deixa de existir.

Oscilação: perto de 0, a função vai e volta entre −1 e 1 cada vez mais depressa, sem se acomodar.

Continuidade: quando o limite é o valor

Na maioria das funções do dia a dia — polinômios, exponenciais, seno e cosseno —, o limite em a é simplesmente f(a): basta substituir. Essas funções são contínuas, e o gráfico delas se desenha sem tirar o lápis do papel.

O limite só pede trabalho onde a conta direta falha: um 0/0, uma divisão por zero, um salto. É justamente o caso da velocidade num instante — e por isso o limite é a peça que faltava.

Truque do 0/0. Muitas vezes dá para simplificar antes de substituir: (x² − 1)/(x − 1) = (x − 1)(x + 1)/(x − 1) = x + 1, para x ≠ 1. A simplificação vale perto do ponto, e é isso que o limite olha. Quando não dá para simplificar, a regra de L’Hôpital costuma resolver.

Limites no infinito

Também se pergunta para onde vai uma função quando x cresce sem parar. A pergunta é a mesma — de que valor ela se aproxima —, só que agora quem se aproxima é o “fim” do eixo.

Dividir 1 por números cada vez maiores dá números cada vez mais perto de zero.

A definição do número e, que veio de juros compostos cada vez mais frequentes.

Uma soma infinita é o limite das somas parciais: a soma da progressão geométrica.

Limites na estatística

Lei dos grandes números. A média de muitas repetições se aproxima do valor esperado: é um limite quando o número de repetições vai ao infinito. Veja a média acumulada se acomodando.

Teorema central do limite. O nome já diz: a distribuição da média de n valores se aproxima da normal quando n cresce. Veja o histograma virar sino.

Derivada e integral. A derivada é o limite das taxas médias, e a integral, o limite das somas de retângulos (soma de Riemann). Toda densidade de probabilidade e toda probabilidade de variável contínua dependem dessas duas ideias.

Teste você mesmo

1. Calcule o limite de (x² − 9)/(x − 3) quando x tende a 3.

Ver resposta

Em x = 3 a fórmula dá 0/0. Mas x² − 9 = (x − 3)(x + 3), e para x ≠ 3 a fração é só x + 3. Quando x se aproxima de 3, isso se aproxima de 6.

2. A função f(x) = 2x + 1 é contínua em x = 4. Qual o limite quando x tende a 4?

Ver resposta

Em funções contínuas, o limite é o próprio valor: f(4) = 9. O limite só dá trabalho quando a conta direta não funciona.

3. O limite de 1/x quando x tende a 0 existe?

Ver resposta

Não. Pela direita, 1/x cresce sem parar (vai a +∞); pela esquerda, cai sem parar (vai a −∞). Os dois lados nem concordam entre si, e nenhum vai para um número.

4. Para onde vai (1 + 1/n)ⁿ quando n cresce sem parar?

Ver resposta

Para e ≈ 2,71828: com n = 10 dá 2,594; com n = 1.000, 2,717; com n = 1 milhão, 2,718280. Veja na fórmula do número e.

5. Usando sen x / x → 1 quando x → 0, quanto vale o limite de sen(3x)/x?

Ver resposta

Escreva sen(3x)/x = 3 · sen(3x)/(3x). Quando x → 0, 3x também → 0, e a segunda parte vai a 1. O limite é 3.
