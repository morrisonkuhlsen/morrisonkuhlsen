O que significa cada termo

Covariância
Mede a relação linear entre duas variáveis. Um valor positivo indica uma relação direta, um negativo indica uma relação inversa.
Somatório
Soma os produtos dos desvios para todas as 'n' observações do conjunto de dados.
Desvio de X
A diferença entre cada valor de X (xi) e a média de X (μx). Mostra o quanto cada ponto se afasta da média.
Desvio de Y
A diferença entre cada valor de Y (yi) e a média de Y (μy). Mostra o quanto cada ponto se afasta da média.
Número de Observações (n)
O número total de pares de observações no conjunto de dados. Normaliza a soma para obter a média dos produtos dos desvios.
