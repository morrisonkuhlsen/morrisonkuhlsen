Exemplo: resolva x² − 5x + 6 = 0, ou seja, a = 1, b = −5 e c = 6. Troque os coeficientes para resolver a sua equação.

Passo a passo

    O que significa cada termo

    Solução (x)
    Representa as raízes ou soluções de uma equação quadrática do tipo ax² + bx + c = 0.
    Coeficiente 'b' Negativo
    O oposto do coeficiente 'b', que é o termo que acompanha 'x' na equação.
    Mais ou Menos (±)
    Indica que a fórmula gera duas soluções: uma somando a raiz do discriminante e outra subtraindo.
    Discriminante (Δ)
    A expressão b² − 4ac, chamada de discriminante (Δ). Se Δ > 0, há duas raízes reais; se Δ = 0, uma raiz dupla; se Δ < 0, duas raízes complexas conjugadas.
    Divisor (2a)
    O dobro do coeficiente 'a', que é o termo que acompanha x². Este valor normaliza a expressão.
