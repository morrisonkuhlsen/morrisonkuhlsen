Exemplo: numa sala com 23 pessoas, qual a chance de pelo menos duas fazerem aniversário no mesmo dia? A intuição diz que é pequena, já que o ano tem 365 dias. Troque os valores para calcular o seu caso.

Passo a passo

    O que significa cada termo

    Probabilidade de Coincidência (P(A))
    A chance de pelo menos duas das n pessoas fazerem aniversário no mesmo dia. Supõe que os aniversários são independentes e que todos os dias são igualmente prováveis.
    Evento Complementar (1 −)
    Contar as coincidências diretamente exigiria somar casos com um par, dois pares, um trio e assim por diante. É mais simples calcular o oposto, todos os aniversários diferentes, e subtrair de 1.
    Fatorial dos Dias (d!)
    Junto com (d − n)!, conta as formas de dar a cada pessoa um dia diferente: d escolhas para a primeira, d − 1 para a segunda, até d − n + 1 para a última. Com d = 365, o ano sem o dia 29 de fevereiro.
    Dias que Sobram ((d − n)!)
    Cancela os fatores de d! que não são usados: dos d dias, só n são ocupados. A fração d!/(d − n)! é o produto d · (d − 1) · … · (d − n + 1).
    Total de Possibilidades (dⁿ)
    Todas as formas de distribuir os aniversários das n pessoas, com repetição permitida: cada uma tem d dias possíveis. A fração inteira é a probabilidade de todos os dias serem diferentes.
