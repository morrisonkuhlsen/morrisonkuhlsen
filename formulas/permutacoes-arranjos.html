    O que significa cada termo

    Arranjo (A(n, k))
    Quantas sequências ordenadas de k itens diferentes dá para formar com n itens: pódios, senhas sem repetição, filas.
    Fatorial de n (n!)
    Todas as ordens possíveis dos n itens: n · (n − 1) · … · 1. Quando k = n, o arranjo é a permutação, n!.
    Fatorial do que Sobra ((n − k)!)
    Cancela os fatores dos itens que ficam de fora. O que sobra é n · (n − 1) · … · (n − k + 1): n opções para a primeira posição, uma a menos para cada seguinte.
