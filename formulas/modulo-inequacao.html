Exemplo: a temperatura de uma estufa deve ficar a no máximo 1,5 °C dos 22 °C ideais: |x − 22| ≤ 1,5. Que temperaturas são aceitas? Mude para “pelo menos” para ver o caso contrário. Troque os valores para calcular o seu caso.

    O que significa cada termo

    Inequação com Módulo
    |x − a| é a distância entre x e a na reta, sem sinal. Pedir que seja no máximo r é pedir os x perto de a.
    Limite de Baixo (a − r)
    O ponto mais à esquerda que ainda está a uma distância r do centro.
    Limite de Cima (a + r)
    O ponto mais à direita. Com ≥ no lugar de ≤, a solução vira o lado de fora: x ≤ a − r ou x ≥ a + r.
