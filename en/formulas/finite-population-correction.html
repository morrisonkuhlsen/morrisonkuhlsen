Step by step

    What each term means

    Corrected Sample Size (n)
    The sample size adjusted for populations that are not very large. This correction reduces the required sample size.
    Initial Sample Size (n₀)
    The sample size computed with Cochran's formula (or another), which assumes an infinite population.
    Correction Factor
    The start of the denominator, which adjusts the sample size to the size of the population.
    Initial Sample Minus One (n₀ - 1)
    Part of the correction factor calculation.
    Population Size (N)
    The total number of individuals in the finite population you are studying.
