    What each term means

    Predicted Value (ŷ)
    The estimated value of the dependent variable (Y) for a given value of the independent variable (x).
    Intercept (β₀)
    The predicted value of Y when the independent variable (x) is zero. It is where the regression line crosses the Y axis.
    Slope (β₁)
    The change in the predicted value of Y for each one-unit increase in x. It is the slope of the regression line.
    Independent Variable (x)
    The variable used to predict or explain the variation in the dependent variable (Y).
