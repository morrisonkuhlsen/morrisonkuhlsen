{%- comment -%} Termos do glossário para glossary-tips.js, que transforma a primeira ocorrência de cada um no artigo num link com a definição ao passar o mouse. Cada verbete vira { s: slug, n: termo, d: definição, t: [grafias] }: o termo, a sigla entre parênteses, se houver ("Intervalo interquartil (IQR)" → "Intervalo interquartil" e "IQR"), e as grafias de `tambem`. Todos os verbetes entram, porque um link escrito à mão para o glossário também mostra a definição. Os que não devem ser marcados sozinhos levam "a": 0: os de `auto: false` e os que o próprio artigo aprofunda (um link do glossário de volta para a página em que o leitor já está não ajuda ninguém). {%- endcomment -%} {%- assign lang = page.lang | default: site.lang -%} {%- assign verbetes = site.data.glossario[lang] -%} {%- if verbetes -%} {%- assign aqui = page.url | remove: ".html" | split: "/" | join: "/" -%} {%- capture termos -%}[ {%- assign primeiro = true -%} {%- for v in verbetes -%} {%- assign proprio = false -%} {%- for ref in v.veja -%} {%- assign alvo = ref.u | remove: ".html" | split: "/" | join: "/" -%} {%- if alvo == aqui -%}{%- assign proprio = true -%}{%- endif -%} {%- endfor -%} {%- assign grafias = "" | split: "" -%} {%- if v.termo contains " (" -%} {%- assign partes = v.termo | split: " (" -%} {%- assign sigla = partes[1] | remove: ")" -%} {%- assign grafias = grafias | push: partes[0] | push: sigla -%} {%- else -%} {%- assign grafias = grafias | push: v.termo -%} {%- endif -%} {%- for t in v.tambem -%}{%- assign grafias = grafias | push: t -%}{%- endfor -%} {%- unless primeiro -%},{%- endunless -%} {%- assign primeiro = false -%} {"s":{{ v.slug | jsonify }},"n":{{ v.termo | jsonify }},"d":{{ v.def | jsonify }},"t":{{ grafias | jsonify }}{% if v.auto == false or proprio %},"a":0{% endif %}} {%- endfor -%} ]{%- endcapture -%} {%- assign pagina_glossario = site.pages | where: "ref", "glossario" | where: "lang", lang | first -%} {%- endif -%}
