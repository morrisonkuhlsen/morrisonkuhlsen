Módulo e Valor Absoluto — A Distância na Reta

O módulo de um número, |x|, é a distância dele até o zero: |−5| = 5 e |5| = 5. Ele joga fora o sinal e fica com o tamanho. E |x − a| é a distância entre x e a — é assim que a estatística mede o quanto um valor se afasta de outro.

Módulo é distância

A definição, em duas partes

Para tirar o sinal de um número negativo, basta pegar o oposto dele. Por isso o módulo se define em duas partes:

O “−x” assusta, mas com x negativo ele é positivo: se x = −5, então −x = −(−5) = 5. É o oposto de que se fala nos números negativos. O módulo nunca dá negativo, e só dá zero para o zero.

Outra forma de escrever a mesma coisa: |x| = √(x²). Elevar ao quadrado apaga o sinal, e a raiz quadrada devolve sempre o valor positivo. É por isso que √((−3)²) = 3, e não −3.

Equações e inequações com módulo

Lendo |x − a| como distância, cada pergunta vira um desenho: quais x estão a uma distância r de a? A menos de r? A mais de r? Escolha a, r e o sinal.

Passo a passo

    O resumo, com r positivo

    Igual: dois pontos, um de cada lado de a.

    Menor: um intervalo só, centrado em a. É “perto de a”.

    Maior: dois pedaços, longe de a para os dois lados.

    Se r for negativo ou zero, o desenho resolve sem conta: nenhuma distância é negativa, e só o próprio a está a distância zero de a. A versão com coeficientes, como |2x − 6| ≤ 4, está em inequação modular.

    Armadilhas

    O sinal de fora fica. O módulo tira o sinal só do que está dentro das barras: |−2| = 2, e o menos de fora faz −2.

    Módulo igual a negativo não tem solução. Não é preciso fazer conta: distância não é negativa.

    “Menor que” é um pedaço só, e não x < 3 e x < −3. Escrever só x < 3 deixa entrar o −10, que está a distância 10 do zero.

    Ache o centro com o sinal certo. |x + 1| é a distância até −1, não até 1.

    Na estatística

    Margem de erro. Uma pesquisa dá 42% para um candidato, com margem de erro de 3 pontos. Isso diz que a porcentagem verdadeira p está a no máximo 3 pontos de 42: |p − 42| ≤ 3. É uma inequação modular, e a resposta é o intervalo 39 ≤ p ≤ 45. A conta por trás está em margem de erro e em intervalo de confiança.

    Erro absoluto. Quando uma previsão dá 120 e o valor real é 112, o erro absoluto é |112 − 120| = 8. A média desses erros, o MAE, é uma das formas mais simples de dizer o quanto um modelo erra, sem que os erros para cima e para baixo se cancelem.

    Desvio absoluto e desvio padrão. Os desvios x − x̄ somam zero, porque os negativos compensam os positivos. Para medir a dispersão, é preciso tirar o sinal. O desvio médio absoluto faz isso com o módulo, Σ|x − x̄|/n; o desvio padrão faz com o quadrado. O quadrado é mais fácil de manipular algebricamente, e por isso ganhou a estatística clássica.

    Teste você mesmo

    1. Calcule |−7|, |3 − 10| e −|−2|.

    Ver resposta

    |−7| = 7. |3 − 10| = |−7| = 7. −|−2| = −2: o módulo vale 2, e o menos de fora fica, dando −2.

    2. Qual é a distância entre −4 e 5 na reta?

    Ver resposta

    |−4 − 5| = |−9| = 9. Na reta: 4 casas até o zero e mais 5 até o 5.

    4. Resolva |x + 1| < 4.

    Ver resposta

    |x + 1| é a distância até −1. Menos de 4 de −1: −5 < x < 3, ou S = ]−5, 3[.

    5. Resolva |x| ≥ 2.

    Ver resposta

    Pelo menos 2 longe do zero: x ≤ −2 ou x ≥ 2, ou S = ]−∞, −2] ∪ [2, +∞[.
