Expressões Algébricas — Parênteses, Colchetes e Chaves

Simplificar uma expressão como 5a − [2b + (3a − b) − (a − 2b)] é reescrevê-la de um jeito mais curto sem mudar o valor. Bastam três ferramentas: tirar os grupos de dentro para fora, cuidar do sinal de menos e juntar os termos semelhantes.

Simplifique uma expressão passo a passo

Escolha uma expressão e dê valores a a e b. Cada linha do passo a passo é reescrita a partir da anterior, e embaixo dela aparece quanto ela vale com os seus números: o valor não muda de uma linha para a outra.

Expressões:

Passo a passo

    De dentro para fora

    Parênteses ( ), colchetes [ ] e chaves { } fazem o mesmo papel: juntam um pedaço da expressão num grupo. Os três nomes servem só para enxergar qual grupo está dentro de qual. É a mesma convenção das expressões numéricas; a diferença é que, com letras, a conta de dentro não vira um número só, e o grupo precisa ser aberto.

    Para abrir um grupo, olhe o que está imediatamente antes dele:

    • Um + (ou nada, no começo): o grupo sai e os sinais de dentro ficam como estão. 2b + (3a − b) = 2b + 3a − b.
    • Um −: o grupo sai e todos os sinais de dentro trocam. 5a − (a − 2b) = 5a − a + 2b.
    • Um número: ele multiplica cada termo de dentro, com o sinal junto. −2(2a − b) = −4a + 2b.

    Depois de abrir um grupo, junte o que der para juntar antes de abrir o próximo. Assim a expressão encolhe a cada passo e há menos sinais para errar.

    Dá para começar por fora? Dá: o resultado é o mesmo, desde que cada sinal seja aplicado a todos os termos do grupo, inclusive aos que estão dentro de outro grupo. Começar por dentro é só o caminho em que há menos sinais para acompanhar de uma vez.

    Termos semelhantes

    Dois termos são semelhantes quando têm exatamente a mesma parte com letras: 3a e −a são semelhantes; 2b e 5b também. Já 3a e 3b não são, nem a e a². Juntar termos semelhantes é somar os números da frente (os coeficientes) e manter a letra:

    É como contar coisas: 3 maçãs menos 1 maçã são 2 maçãs, mas 3 maçãs mais 2 laranjas não são 5 “maçãranjas”. Uma letra sozinha tem coeficiente 1: a = 1a e −a = −1a.

    Coeficiente, monômio, termo e grau são o vocabulário da álgebra; o texto Monômios, polinômios e coeficientes explica cada um com calma.

    Uma regra de simplificação só vale se der o mesmo número dos dois lados para quaisquer valores das letras. Arraste a e b: os valores são os mesmos em todos os cards.

    Armadilhas

    O menos pega o grupo inteiro. Não só o primeiro termo: o último também troca, mesmo sendo um número sem letra.

    A distributiva também pega todos. Escrever 4a + 3 é multiplicar só o primeiro termo.

    A letra sozinha vale 1. 6a − a não é 6, nem 6a − 1: é tirar um a de seis.

    Somar não é multiplicar. Somar termos iguais aumenta o coeficiente; multiplicá-los aumenta o expoente.

    Uma letra pode sumir. Se os termos dela se cancelam, o resultado não depende dela. Não é erro; veja o exemplo 7a − [4b − (2a + b) + (a − 3b)] lá em cima.

    Para onde isso leva

    Equações. Antes de isolar o x numa equação do 1º grau, o primeiro passo é quase sempre este: tirar os parênteses e juntar os semelhantes de cada lado.

    Produtos notáveis. Quando um grupo multiplica outro grupo, como (a + b)(a − b), a distributiva vale termo a termo. Os casos que aparecem sempre estão em produtos notáveis.

    Desvios somam zero. Na estatística, com três valores e média x̄ = (x₁ + x₂ + x₃)/3, tirar os parênteses e juntar os semelhantes mostra que os desvios se anulam:

    Porque 3x̄ é justamente x₁ + x₂ + x₃. É por isso que a variância eleva os desvios ao quadrado antes de somar.

    Teste você mesmo

    1. Simplifique 4a − [b + (3a − 2b) − (a + b)].

    Ver resposta

    Parênteses: b + 3a − 2b − a − b. Juntando, 2a − 2b. Tirando o colchete: 4a − 2a + 2b = 2a + 2b.

    Veja passo a passo →

    2. Simplifique 6a − {2b − [a − (3b − a)]}.

    Ver resposta

    De dentro para fora: a − 3b + a = 2a − 3b; depois 2b − 2a + 3b = 5b − 2a; por fim 6a − 5b + 2a = 8a − 5b.

    Veja passo a passo →

    3. Simplifique 2(3a − b) − 3[a − (2b − a)].

    Ver resposta

    O colchete fica 2a − 2b. Distribuindo: 6a − 2b − 6a + 6b = 4b. Os termos em a se cancelam.

    Veja passo a passo →

    4. Calcule 5a − [2b + (3a − b) − (a − 2b)] para a = 7 e b = 5. Simplifique antes de pôr os números.

    Ver resposta

    A expressão simplificada é 3a − 3b. Com a = 7 e b = 5: 21 − 15 = 6. Na expressão original dá o mesmo, mas com bem mais contas.

    Veja passo a passo →

    5. Um aluno escreveu 8a − (3a − 2b) = 5a − 2b. Onde está o erro?

    Ver resposta

    Ele trocou só o sinal do 3a. O menos troca os dois: 8a − 3a + 2b = 5a + 2b. Teste com a = 1 e b = 1: a expressão original dá 8 − (3 − 2) = 7; a resposta do aluno dá 3, e a correta, 7.

    6. Um retângulo tem lados 2a + b e a − b. Escreva o perímetro da forma mais simples e calcule-o para a = 5 e b = 2.

    Ver resposta

    Perímetro: 2(2a + b) + 2(a − b) = 4a + 2b + 2a − 2b = 6a. Com a = 5, dá 30, qualquer que seja b (desde que a − b continue positivo, para o lado existir).
