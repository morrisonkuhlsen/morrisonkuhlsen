Equação do 1º Grau — A Balança

Uma equação é uma balança em equilíbrio com um peso desconhecido, o x. Resolver é descobrir o x sem desequilibrar a balança: tudo o que se faz de um lado, faz-se do outro.

O que se faz de um lado, faz-se do outro

Escolha quantas caixas (a), quantas bolinhas soltas (b) e o peso secreto de cada caixa (x). Depois resolva com os botões.

Resolva uma equação passo a passo

Digite uma equação do 1º grau em x. Pode ter parênteses, frações (com /), decimais (com vírgula) e x dos dois lados. No fim, a prova confere a resposta.

Exemplos:

Passo a passo

    “Passar para o outro lado trocando o sinal”

    É o atalho que todo mundo aprende — e ele é só a balança escrita de um jeito mais curto. Em 3x + 5 = 20, “passar o 5 para o outro lado com sinal trocado” é subtrair 5 dos dois lados:

    Do lado esquerdo, o + 5 e o − 5 se anulam; do lado direito, o − 5 fica. Parece que o 5 “pulou” trocando de sinal. Do mesmo jeito, o 3 que multiplica o x “passa dividindo”: é dividir os dois lados por 3.

    Saber de onde vem o atalho evita os erros dele: o que soma passa subtraindo, o que multiplica passa dividindo — e o 3 de 3x passa dividindo o lado inteiro, não só um termo.

    A ordem: desfaça do último para o primeiro. Em 3x + 5, o x primeiro foi multiplicado por 3 e depois somado com 5. Para chegar ao x, desfaça ao contrário: tire o 5, depois divida por 3 — como tirar os sapatos antes das meias.

    Montar a equação a partir de um problema

    Quase sempre o difícil é escrever a equação; resolver é a parte mecânica. O roteiro:

    1. Chame de x o que o problema pergunta.
    2. Traduza cada frase em conta: “o dobro” é 2x, “5 a mais” é + 5, “o total é 41” é = 41.
    3. Resolva e confira a resposta no texto do problema, não só na equação.

    Exemplo: um táxi cobra R$ 5 de bandeirada e R$ 3 por quilômetro. Uma corrida custou R$ 41. Quantos quilômetros foram? Com x quilômetros, o preço é 3x + 5. Então 3x + 5 = 41, 3x = 36, x = 12 km. Conferindo: 5 + 3 × 12 = 41.

    Armadilhas

    Dividir é dividir tudo. Dividindo por 3, cada termo dos dois lados é dividido — não só o 3x.

    Não pare no −x. −x é −1 vezes x: multiplique os dois lados por −1.

    A distributiva pega todo mundo. O 2 multiplica o x e o 3. Esquecer o segundo dá 2x − 3.

    Menos antes dos parênteses troca todos os sinais de dentro — veja números negativos.

    Quando o x some. Se sobrar algo como 0 = 5, não há solução; se sobrar 0 = 0, qualquer x serve.

    Para onde a equação do 1º grau leva

    Equação do 2º grau. Quando aparece x², a balança não basta, mas a ideia de fazer o mesmo dos dois lados continua — é ela que deduz a fórmula quadrática na equação do 2º grau.

    Escore z. A fórmula z = (x − μ)/σ é uma equação do 1º grau em x. Para achar o valor que fica 2 desvios acima da média, isola-se o x: x = μ + zσ. O escore z faz isso nos dois sentidos.

    Regressão. Uma reta de regressão y = a + bx prevê y a partir de x. Para saber qual x leva a um y desejado, resolve-se uma equação do 1º grau — veja a regressão linear.

    Teste você mesmo

    1. Resolva 4x − 3 = 25.

    Ver resposta

    Some 3 aos dois lados: 4x = 28. Divida por 4: x = 7. Prova: 4 × 7 − 3 = 25.

    2. Resolva 7x + 2 = 3x + 18.

    Ver resposta

    Subtraia 3x: 4x + 2 = 18. Subtraia 2: 4x = 16. Divida por 4: x = 4.

    Veja passo a passo →

    3. Resolva 3(x + 2) = 5x − 4.

    Ver resposta

    Distributiva: 3x + 6 = 5x − 4. Subtraia 5x: −2x + 6 = −4. Subtraia 6: −2x = −10. Divida por −2: x = 5.

    Veja passo a passo →

    4. Resolva x/3 − 1 = 4.

    Ver resposta

    Some 1: x/3 = 5. Multiplique por 3: x = 15.

    Veja passo a passo →

    5. A soma de três números consecutivos é 72. Quais são?

    Ver resposta

    Chamando o primeiro de x: x + (x + 1) + (x + 2) = 72, ou 3x + 3 = 72. Então 3x = 69 e x = 23. Os números são 23, 24 e 25.

    6. Numa prova com peso 2 e um trabalho com peso 1, a média ponderada é (2 × prova + trabalho) ÷ 3. Quem tirou 6 no trabalho precisa de quanto na prova para ficar com média 7?

    Ver resposta

    (2x + 6) ÷ 3 = 7. Multiplique por 3: 2x + 6 = 21. Então 2x = 15 e x = 7,5. Veja também a média ponderada.
