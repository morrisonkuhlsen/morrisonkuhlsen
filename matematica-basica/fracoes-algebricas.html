Frações Algébricas — Simplificar, Somar e o Buraco no Gráfico

Uma fração algébrica é uma fração com letras no denominador, como (x² − 4)/(x − 2). As regras são as mesmas das frações com números, com uma ferramenta a mais — fatorar — e um cuidado a mais: o denominador nunca pode ser zero.

Passo a passo

    A condição de existência

    Dividir por zero não tem resultado, então uma fração algébrica só existe para os x que não zeram o denominador. Para achá-los, iguale o denominador a zero e resolva: em (x² − 4)/(x − 2), x − 2 = 0 dá x = 2, e a condição é x ≠ 2.

    Ao simplificar, o fator que causava o problema some, e a forma simplificada passa a funcionar também em x = 2: x + 2 dá 4. Mas a fração original continua sem valor ali. As duas são iguais em todo o resto, e por isso se escreve:

    No gráfico, a original é a reta y = x + 2 com um buraco em (2, 4). Já em 2/x, o x de baixo não corta: em x = 0 não há buraco, e sim uma assíntota — a curva dispara para cima e para baixo. A diferença entre buraco e assíntota volta, com mais detalhes, nos limites.

    Armadilhas

    Só se corta o que multiplica. Para cortar, o fator tem de multiplicar o numerador inteiro e o denominador inteiro. Na dúvida, fatore primeiro.

    Fatores opostos cortam deixando −1. 3 − x = −(x − 3), então a fração é −(x − 3)/(x − 3) = −1, para x ≠ 3.

    Soma de quadrados não fatora. x² + 9 não é (x + 3)(x − 3) — essa é a diferença x² − 9. Esta fração não simplifica.

    A condição vem da fração original. Ache os x proibidos antes de simplificar; depois, o fator que os denunciava já sumiu.

    Na estatística

    Chance e probabilidade. A chance (odds) de um evento de probabilidade p é c = p/(1 − p): com p = 0,8, a chance é 0,8/0,2 = 4, ou “4 para 1”. Para voltar da chance para a probabilidade, isola-se p, mexendo numa fração algébrica:

    Média harmônica. Um carro vai a 60 km/h e volta pelo mesmo caminho a 40 km/h. A velocidade média não é 50: ida e volta levam d/60 + d/40 horas para 2d quilômetros. O d corta, porque é fator de tudo:

    Com letras no lugar de 60 e 40, sai a fórmula da média harmônica de dois números: 2ab/(a + b).

    Teste você mesmo

    1. Simplifique (x² − 25)/(x + 5).

    Ver resposta

    x² − 25 = (x + 5)(x − 5). Cortando (x + 5): x − 5, para x ≠ −5.

    Veja passo a passo →

    2. Simplifique (3x² − 12x)/(x² − 4x).

    Ver resposta

    Em cima, 3x(x − 4); embaixo, x(x − 4). Corta tudo menos o 3: 3, para x ≠ 0 e x ≠ 4. O gráfico é uma reta horizontal com dois buracos.

    Veja passo a passo →

    3. Calcule 1/x + 1/(x + 1).

    Ver resposta

    Denominador comum x(x + 1): ((x + 1) + x)/(x(x + 1)) = (2x + 1)/(x(x + 1)), para x ≠ 0 e x ≠ −1.

    Veja passo a passo →

    4. Para que valores de x a fração (x + 1)/(x² − 9) não existe?

    Ver resposta

    x² − 9 = 0 quando x² = 9: x = 3 ou x = −3. O numerador não importa para isso.

    5. Um aluno “simplificou” (x + 8)/(x + 4) para 2. Teste com x = 1 e explique o erro.

    Ver resposta

    Com x = 1: 9/5 = 1,8, e não 2. Ele cortou o x, que é parcela (está somado), e depois fez 8/4. A fração não simplifica: nem o numerador nem o denominador têm fator em comum.

    6. Uma chance de 3 para 1 (c = 3) corresponde a que probabilidade?

    Ver resposta

    p = c/(1 + c) = 3/4 = 0,75. Confere: 0,75/0,25 = 3.
