Somatório — A Notação Σ

O Σ (sigma, o S grego) é um jeito curto de escrever uma soma comprida. Quase toda fórmula da estatística tem um: a média, a variância, a covariância, a regressão. Ler o Σ é ler a receita da conta.

Lendo o Σ

As partes do Σ

  • Embaixo, o índice e onde ele começa: i = 1. O nome do índice não importa — i, j ou k dão a mesma soma.
  • Em cima, onde ele para: n, o número de dados.
  • À direita, o termo: o que se calcula para cada i. Com dados, xᵢ é o i-ésimo valor da lista: x₁ é o primeiro, x₂ o segundo.

Quando os limites são óbvios — somar todos os dados —, eles costumam ser omitidos: Σxᵢ quer dizer “some todos os x”.

Somando uma lista de dados

Digite os dados e escolha a soma. A tabela faz uma coluna para cada termo — é assim que se calcula à mão — e a última linha é o Σ de cada coluna.

    O Σ nas fórmulas da estatística

    Com o Σ lido, as fórmulas viram instruções. Cada uma diz o que calcular para cada dado e o que fazer com a soma:

    Média: some os valores e divida por quantos são.

    Variância: para cada valor, desvio ao quadrado; some; divida por n − 1. A raiz é o desvio padrão.

    Média ponderada: dois Σ, um em cima e outro embaixo. Veja a média ponderada.

    Covariância: o produto dos dois desvios, somado. Veja a covariância.

    E o Σ tem um primo, o Π (pi maiúsculo), que multiplica em vez de somar: Π xᵢ = x₁ · x₂ · … · xₙ. Ele aparece na média geométrica e na inflação acumulada.

    Armadilhas

    Onde está o quadrado. Dentro do Σ, eleva-se cada termo; fora, eleva-se a soma pronta. Com 2, 4, 9: 101 contra 225.

    Termo sem i também conta. O 3 é somado uma vez para cada i.

    Contar os termos. De 3 a 7 são 7 − 3 + 1 = 5, não 4. O “+ 1” é o mais esquecido.

    Os desvios sempre se anulam. Se a sua soma de desvios não deu zero (ou quase, por arredondamento), há erro na média.

    Teste você mesmo

    1. Escreva por extenso e calcule Σ de i = 2 até 5 de i².

    Ver resposta

    2² + 3² + 4² + 5² = 4 + 9 + 16 + 25 = 54.

    Veja no Σ →

    2. Escreva 3 + 6 + 9 + 12 + 15 com Σ.

    Ver resposta

    Cada termo é 3 vezes um contador de 1 a 5: Σ de i = 1 até 5 de 3i, que dá 3 × (1 + 2 + 3 + 4 + 5) = 45.

    3. Para os dados 1, 3, 5, 7, calcule Σxᵢ, Σxᵢ² e (Σxᵢ)².

    Ver resposta

    Σxᵢ = 16. Σxᵢ² = 1 + 9 + 25 + 49 = 84. (Σxᵢ)² = 16² = 256.

    Veja na tabela →

    4. Com os mesmos dados, calcule a variância pelo atalho Σx² − (Σx)²/n, dividido por n − 1.

    Ver resposta

    84 − 256/4 = 84 − 64 = 20. Dividido por n − 1 = 3: s² = 20/3 ≈ 6,67.

    Confira pelos desvios →

    5. Se Σxᵢ = 40 para n = 8 valores, quanto vale Σ(xᵢ + 2)? E Σ 5xᵢ?

    Ver resposta

    Σ(xᵢ + 2) = Σxᵢ + Σ2 = 40 + 8 × 2 = 56. Σ 5xᵢ = 5 × 40 = 200.
